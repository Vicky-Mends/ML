# Introduction to Machine Learning

This repository contains coursework, programming assignments, and projects from my **Introduction to Machine Learning Class at NYU Tandon School of Engineering**.

The repository explores fundamental machine learning concepts through mathematical foundations, computational methods, data analysis, and hands-on implementation. It includes work involving data preparation, exploratory analysis, predictive modeling, and the evaluation of machine learning methods.

## Topics

The repository covers practical work related to:

- **Data preparation and exploration** — inspecting datasets, handling missing values, transforming variables, and preparing data for analysis.
- **Regression** — understanding and implementing methods for predicting continuous outcomes.
- **Classification** — exploring methods for assigning observations to categories.
- **Model optimization and selection** — examining model fitting, regularization, and approaches to selecting appropriate models.
- **Clustering and dimensionality reduction** — exploring methods for identifying structure in data and representing data in lower-dimensional spaces.
- **Model evaluation** — assessing predictive performance and understanding model validation.
- **Data visualization and interpretation** — communicating patterns, relationships, and analytical findings.

Specific topics and techniques are represented according to the projects and assignments included in the repository.

## Tools and Technologies

- **Programming:** Python
- **Data manipulation and numerical computing:** Pandas, NumPy
- **Data visualization:** Matplotlib, Seaborn
- **Machine learning:** Scikit-learn and related Python tools, where applicable
- **Development environments:** Jupyter Notebook, Google Colab

## Repository Organization

Projects and assignments are organized into separate directories. Depending on the project, each directory may contain Jupyter notebooks, project documentation, datasets or links to data sources, and supporting files.

## Objective

The repository provides a practical record of machine learning methods and their applications, with an emphasis on understanding the data, implementing analytical approaches, interpreting results, and evaluating their limitations.
