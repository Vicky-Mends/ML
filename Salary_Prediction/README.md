# Salary Prediction — Data Preparation

## Overview
This project explores data preparation for a machine learning task involving salary prediction.

## Work completed
- Explored and prepared job listing data.
- Processed categorical features using encoding techniques.
- Converted job description text into numerical features using text vectorization.
- Prepared the feature matrix (`X`) and target variable (`y`).
- Organized the data for further machine learning analysis.

## Tools
- Python
- pandas
- scikit-learn
- Jupyter Notebook

# Project status

Data preparation completed. Training and evaluation of a salary prediction model have not yet been completed.
